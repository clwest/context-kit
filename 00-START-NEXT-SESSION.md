## Queued Investigations

- **Pre-commit hook for inventory currency.** Session 3 surfaced the
  ordering bug: `inventory --write` is most accurate when run AFTER
  staging all other changes (so `git ls-files` reflects the full
  about-to-commit state). A pre-commit hook that does
  `git add -A && context-kit inventory --write && git add docs/CONTEXT_KIT_INVENTORY.md`
  would automate this. Worth doing once we have at least one CI run
  catching real drift.
- **Narrative anchor TL;DR scale-line drift.** The narrative anchor
  has its own scale numbers; the inventory generator doesn't rewrite
  it. Either accept manual maintenance there, or add a second
  managed-block in `CONTEXT_KIT_WHAT_IT_IS.md` for those few values.
- **`_cli_subcommands` trusts in-process build_parser.** If anyone
  customizes their `context_kit.py` heavily in their generated
  project, the introspection still reports our subcommands. Not yet
  a real bug, but logged.
